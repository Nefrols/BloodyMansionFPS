# КРОВАВЫЙ ОСОБНЯК

Воксельный FPS в одном HTML-файле: разрушаемая усадьба, боты с ИИ, пять видов оружия, режимы FFA и «ОДИН ПРОТИВ ВСЕХ».

**Играть:** https://nefrols.github.io/BloodyMansionFPS/

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| SHIFT | бег |
| ПРОБЕЛ | прыжок |
| C | присед |
| ЛКМ | огонь |
| ПКМ | прицел |
| R | перезарядка |
| 1 / 2 | пистолет / основное |
| Q / колесо | смена оружия |
| TAB | таблица |
| ESC | пауза |

## Телефоны и планшеты

На сенсорных устройствах экранные кнопки и джойстики включаются сами:

- **левый стик** — движение, до упора вперёд — бег;
- **палец по экрану** — обзор;
- **ОГОНЬ** — держишь кнопку, стрельба идёт; ведёшь палец по кнопке — прицел доворачивается, не отпуская огня (как в PUBG Mobile / CODM);
- **⌖ прицел** (переключатель), **↑ прыжок**, **ПРИСЕД** (переключатель), **ПЕРЕЗАР.**, **СМЕНА** оружия, **II пауза**;
- **автоприцел** — мягко подтягивает прицел к видимой цели, когда стреляешь или смотришь в прицел; отключается галочкой в меню.

Страница заперта от жестов браузера: отключены пинч-зум, зум двойным тапом, выделение текста, контекстное меню и оттягивание страницы.

Мобильный профиль рендера: без MSAA, pixel ratio ≤ 1, отключено размытие краёв в прицеле, HUD разведён по верхним углам, чтобы не лежать под пальцами. В портретной ориентации игра просит повернуть устройство.

Во фуллскрине включаются блокировка ориентации (ландшафт) и Wake Lock, чтобы экран не гас во время боя. Звук разблокируется первым тапом по странице и автоматически возобновляется после сворачивания.

Сенсорный режим можно включить/выключить принудительно: `?touch=1` / `?touch=0` в адресе страницы.

## Технически

Один файл `index.html`, без сборки и зависимостей в репозитории. Three.js и cannon-es подгружаются с CDN (jsDelivr) через import map, поэтому страницу нужно открывать по HTTP, а не через `file://`.

Локальный запуск:

```sh
python -m http.server 8765
# http://127.0.0.1:8765/
```

## Публикация

GitHub Pages, ветка `main`, корень репозитория. Каждый пуш в `main` обновляет страницу автоматически.
